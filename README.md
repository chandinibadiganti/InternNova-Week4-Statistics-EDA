# InternNova Week 4 – Statistics, Data Visualization and EDA

## Project Overview
This project focuses on statistical analysis, data visualization, and Exploratory Data Analysis (EDA) using the UCI Online Retail Dataset. The aim is to understand retail transaction data, identify meaningful patterns, and generate useful business insights.

## Dataset
- **Name:** UCI Online Retail Dataset
- **Source:** UCI Machine Learning Repository
- **Columns:** InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, Country

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Tasks Completed

1. **Mean, Median and Mode** – Calculated measures of central tendency.
2. **Variance and Standard Deviation** – Analyzed data distribution and variation.
3. **Correlation and Probability** – Examined relationships and calculated probabilities.
4. **Outlier Detection** – Identified potential outliers using the IQR method.
5. **Matplotlib Visualizations** – Created line, bar, pie, histogram, and scatter plots.
6. **Seaborn Visualizations** – Created count plots, box plots, heatmaps, and pair plots.
7. **Data Inspection and Cleaning** – Checked missing values, duplicates, and cleaned the dataset.
8. **Correlation Analysis and Insights** – Interpreted relationships and identified key findings.
9. **Business Recommendations** – Suggested improvements based on the analysis.

## How to Run
1. Download the notebook from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the `.ipynb` notebook.
4. Upload the UCI Online Retail dataset when prompted by the notebook.
5. Run the cells in sequence to view the analysis and visualizations.
